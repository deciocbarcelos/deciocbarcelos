## Projetos em destaque

### Plataforma de cursos DSB

Aplicação educacional desenvolvida com Python, Flet e SQLite. O projeto reúne catálogo de cursos, autenticação, matrículas, acompanhamento de progresso, perfil do aluno, administração de conteúdo e emissão de certificados. A versão pública foi preparada para funcionar localmente com dados demonstrativos e sem depender de credenciais ou serviços privados.

### Índice invertido com PATRICIA e Hash

Projeto acadêmico desenvolvido em C para indexação e busca em títulos e resumos de trabalhos de Ciência da Computação. Compara uma árvore PATRICIA e uma tabela Hash encadeada, incluindo pré-processamento dos textos, consultas, ordenação por relevância com TF-IDF e análise de desempenho e uso de memória.

### Caminho de dados RISC-V

Implementação acadêmica em Verilog dos principais módulos de um processador RISC-V, incluindo banco de registradores, ULA, unidade de controle, memórias, multiplexadores e contador de programa. O projeto foi simulado e testado com Icarus Verilog.

### Análise exploratória de dados

Projetos com Python, Pandas, Matplotlib e Seaborn para limpeza, transformação e visualização de dados, incluindo análises de transporte público com a base BRBUS e estudos de comportamento de vendas.
